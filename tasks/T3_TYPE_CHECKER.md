# T3: Implement Type Checker with de Bruijn Scoping (Not Started)

> ❌ Status: Not Started

## Description
Implement the Hindley-Milner type inference engine that uses **de Bruijn index scope** instead of named environments.

Current `type_checker.py` assumes variable names (`env.lookup("x")`). PAL/Ø has no identifiers — bound variables are referenced by depth (index 0 = innermost binder).

This task must:
- Traverse the AST generated by T2
- Generate type constraints based on opcode semantics
- Solve them using Robinson unification
- Track scope depth via stack, not variable names
- Annotate AST nodes with inferred types

## Implementation Requirements

### Input
AST from T2: `Lambda(body=Lambda(body=BinaryOp(+, Var1, Var0)))`

### Output
Annotated AST:
```python
Lambda(
  body=Lambda(
    body=BinaryOp("+", 
      Variable(index=1, type=Int),
      Variable(index=0, type=Int)
    ), 
    type=(Int → Int)
  ), 
  type=(Int → Int → Int)
)
```

### Key Logic
- Use a `ScopeStack` instead of `TypeEnvironment`
- On `LAMBDA`: push new scope (depth increases by 1)
- On `VARx`: lookup type at depth = x+1 in stack (0-indexed: VAR0 → depth=1, VAR1 → depth=2)
- For `TANNOT` (`⦂`): parse second child as a *type expression*, convert to `Type` via `node_to_type()`
- Constraints:
  - Binary ops: left and right must match op’s expected types (from Prelude)
  - Application: arg type must unify with function parameter
  - Conditional: condition must be `𝔹`, then/else branches must have same type

### Scope Stack Example: "λλ+₁₀"
```
Scope Level | Variables (depth = level index)
---------------------------------------------
Level 2     | [x] ← outer lambda (VAR1 refers to this)
Level 1     | [y, x] ← inner lambda (VAR0 refers to y)
Level 0     | [] ← global
```
- `VAR0` → index=0 → current scope level 1 → pick element at index 0 = `y`
- `VAR1` → index=1 → current scope level 1 → pick element at index 1 = `x`

## Acceptance Criteria

1. `type_check(Lambda(body=Lambda(body=BinaryOp("+", Var1, Var0))))` → type `(Int → Int → Int)`
2. `type_check(Conditional(Var0, Literal(1), Literal(0)))` → Error: Var0 has no binding in scope
3. `type_check(TANNOT(BinaryOp("+", Var0, Var1), TINT))` → type = `Int`
4. Constraints are correctly generated and unified
5. Errors include source location from AST node
6. Type annotations stored on AST nodes (e.g., `node.typ`)
